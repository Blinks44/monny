# Monny 1.1.1

AI limits now support ClinePass, Codebuff, Amp, Augment and Nous Portal, alongside the six existing tools. Monny uses the sign-in already set up in each tool. Enable AI limits in Settings and choose which tools to check.

- Added vendor logos for all 11 tools.
- Fixed the history legend layout when many tools are enabled.
- Service requests that carry sign-in credentials now refuse redirects.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** below and drag Monny into Applications. Requires Apple silicon and macOS 26 or later.

The app is signed but not notarized by Apple. A new download may need **System Settings → Privacy & Security → Open Anyway** on first launch. See the [installation guide](https://github.com/Blinks44/monny#install).

Check the download with the attached **SHA256SUMS.txt**: `shasum -a 256 -c SHA256SUMS.txt`.

## Known limits

AI limits are off by default. Amp and Augment need their CLI installed; Nous Portal uses the Hermes Agent session. Service output and quota endpoints can change. The five new integrations passed fixture tests; comparison with real signed-in accounts is still pending.

Build 67. Automated tests and native Light/Dark rendering checks ran on macOS 27.0.1. Charging compatibility and readings on other Mac models retain their existing limits.
