# Monny 1.2.0

Find out what is holding a port. Type `3002`, `localhost:3002` or a local URL into the Processes search and Monny shows the process listening on it: where it was started from, its executable, its parent and every port it listens on. Quit or Force Quit ends only that process, and Monny reports the result only after the process has exited.

- Search by PID as well. A plain number matches both a PID and a port.
- Processes that keep a core busy for over a minute appear at the top of the list, so you can quit them in one click.
- The sort menu moved next to the search field.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** below and drag Monny into Applications. Requires Apple silicon and macOS 26 or later.

The app is signed but not notarized by Apple. A new download may need **System Settings → Privacy & Security → Open Anyway** on first launch. See the [installation guide](https://github.com/Blinks44/monny#install).

Check the download with the attached **SHA256SUMS.txt**: `shasum -a 256 -c SHA256SUMS.txt`.

## Known limits

Monny sees only processes running under your account, like the rest of the Processes list. A port held by another user or by the system is not shown, so Monny does not say a port is free, only that none of your processes uses it. macOS has no public way to tell that an app is not responding, so the top section lists busy processes, not hung ones.

Build 69. Automated tests ran on macOS 27.0.1, and the new search was checked on an installed build.
