# Monny 1.2.1

A small update with clearer wording and one more row in the process list.

- The Processes tab shows nine apps instead of eight, using the space freed by the new sort menu.
- Reworded unclear and awkward text in Russian, German, French, Spanish and Chinese. For example, the Spanish battery state no longer reads like "downloading", and thermal states now use the same words across the app.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** below and drag Monny into Applications. Requires Apple silicon and macOS 26 or later.

The app is signed but not notarized by Apple. A new download may need **System Settings → Privacy & Security → Open Anyway** on first launch. See the [installation guide](https://github.com/Blinks44/monny#install).

Check the download with the attached **SHA256SUMS.txt**: `shasum -a 256 -c SHA256SUMS.txt`.

Build 72. Automated tests ran on macOS 27.0.1, and the process list was checked on an installed build.
