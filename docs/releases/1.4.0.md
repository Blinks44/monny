# Monny 1.4.0

- **Processes** now shows each app’s download and upload speed. Choose **Network** to see which apps are using the most bandwidth.
- The **Network** page in the dashboard now lists apps with their download and upload speeds.
- Daily traffic now shows the date, download, upload and total for each of the last seven days.
- Adjusted the spacing at the bottom of the menu bar panel.

Daily traffic is an estimate recorded while Monny is running. Days without readings show a dash.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** below and drag Monny into Applications. Requires Apple silicon and macOS 15 or later.

The app is signed but not notarized by Apple. A new download may need **System Settings → Privacy & Security → Open Anyway** on first launch. See the [installation guide](https://github.com/Blinks44/monny#install).

Check the download with the attached **SHA256SUMS.txt**: `shasum -a 256 -c SHA256SUMS.txt`.

Build 80. Automated tests ran on Apple silicon with macOS 27.2.
