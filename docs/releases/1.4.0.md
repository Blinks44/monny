# Monny 1.4.0

- **Processes** can be sorted by **Network** to see which apps download and upload the most right now.
- The **Network** page in the dashboard lists the apps using the network, with download and upload speed.
- Traffic for the last seven days is now a table: date, download, upload and total for each day. It counts only the time Monny was running; days without data show a dash.
- Fixed spacing at the bottom of the menu bar panel.

With a VPN on, the same traffic appears under both the app and the VPN client.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** below and drag Monny into Applications. Requires Apple silicon and macOS 15 or later.

The app is signed but not notarized by Apple. A new download may need **System Settings → Privacy & Security → Open Anyway** on first launch. See the [installation guide](https://github.com/Blinks44/monny#install).

Check the download with the attached **SHA256SUMS.txt**: `shasum -a 256 -c SHA256SUMS.txt`.
