# Monny 1.5.0

- Added Kimi Code limits, including international accounts, using your existing sign-in.
- Fixed CPU/GPU temperatures dropping when cores are idle.
- The CPU core list now fits Macs with more cores.
- Fixed fan status, clipped temperature charts and crowded sensor legends.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** and drag Monny into Applications. Apple silicon, macOS 15 or later.

Signed, not notarized. First launch may require **System Settings → Privacy & Security → Open Anyway**.

Build 87. Tested on macOS 27.2.
