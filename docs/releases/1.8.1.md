## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** below and drag Monny into Applications. Requires Apple silicon and macOS 15 or later.

The Apple Development signature is in place. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch because the app is distributed without Apple notarization. See the [installation guide](https://github.com/Blinks44/monny#install).

Verify the download with the attached **SHA256SUMS.txt** using `shasum -a 256 -c SHA256SUMS.txt`.

Build 101. Automated tests ran on macOS 27.2.1 on Apple silicon.
