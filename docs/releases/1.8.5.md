# Monny 1.8.5

- AI limit checks now run concurrently across installed tools and update each card as soon as its service responds instead of waiting for the slowest service.
- Background AI polling adapts per tool: every 5 minutes while usage changes with notifications on, every 14 minutes when idle or with notifications off (keeping history charts continuous), sleeping until reset when all windows are exhausted, and every 30 minutes for signed-out or missing tools. Recent cached readings skip an immediate network fetch on launch.
- Quota windows now appear in a consistent order across tools (5-hour windows before weekly, and Antigravity Gemini before Claude/GPT and Argon).
- Gemini CLI caches its project lookup for two hours (invalidated on auth failure) so routine checks make one request instead of two.

## Install or update

Choose **Check for Updates** in Monny, or download **Monny.dmg** and drag Monny into Applications. Requires Apple silicon and macOS 15 or later.

The app is signed with Apple Development and distributed without Apple notarization. On first launch, macOS may require **System Settings → Privacy & Security → Open Anyway**. See the [installation guide](https://github.com/Blinks44/monny#install).

Verify the download with the attached **SHA256SUMS.txt** using `shasum -a 256 -c SHA256SUMS.txt`.
