## Implementation decision and result — 2026-11-08

The user authorized all qualifying additions plus website listings, accepting issue-based real-account follow-up. Implemented nine sources: OpenCode Go, Kilo, API-only Kiro, Alibaba Token Plan, Alibaba Coding Plan, local Windsurf, CodeRabbit counts, eligible work-account Gemini CLI and Hugging Face ZeroGPU. The original screening remains below as dated rationale; implementation details here supersede tentative choices. New readers use native Foundation/system SQLite and the existing bounded child runner; no package/source was copied or installed.

- **OpenCode Go:** default `.local/share/opencode` only. Read active v2 `credential` table rows (Go preferred over general OpenCode; duplicate selected integration rejected), otherwise legacy `auth.json` only when the v2 table is absent. OAuth expiry checked with a safety margin. Fixed `GET /inference/go/v1/usage`; no cookie or old-account fallback. Reported session/weekly/monthly meters each have separate history; monthly duration is unknown.
- **Kilo:** default CLI `kilo.access`; JWT expiry when present. GET tRPC batch `user.getCreditBlocks,kiloPass.getState` only, not payment-method discovery. Explicit USD balance and pass base+reported bonus allowance stay separate; unknown schemas stay unavailable. No organization guessing, renewal or purchased-credit percentage bar.
- **Kiro:** require one token and explicit valid profile in CLI SQLite; fixed US East/Frankfurt hosts only. Direct GetUsageLimits, no chat or whoami subprocess. Plan usage subtracts explicitly reported overage, rejects ambiguous bonuses; optional overage has its own label and does not enter plan history. Missing profile, unsupported region or incomplete plan reading is unavailable. No monthly duration is invented.
- **Bailian:** use the user's saved default console/profile/region, with no profile switches or region probes. Official CLI at `cadc301d078f0fd1f2c56f7bf94f32c55bbb055d` supplies direct JSON from `bl usage token-plan --output json` (per* ratio/reset fields, hasQuotaData) and `bl usage coding-plan --output json` (per5Hour/perWeek/perBillMonth counters/ratios). This replaces the screening's provisional custom console calls: the supported CLI now supplies monthly data directly. These commands require console auth; model-only keys and Team seat aggregation are outside this reader. The CLI owns saved sign-in; Monny never invokes login/refresh. Bounded execution, null stdin and narrow environment apply. CLI-internal expiry behavior is a real-account check.
- **Windsurf:** read one cachedPlanInfo entry with reported quotaUsage or message/action counters. Never use database mtime as reading time: `sourceDateUnknown` keeps readings visibly cached/stale and excludes them from alerts/history. No browser or web API fallback.
- **CodeRabbit:** deliberately use the established `coderabbit usage` text report, not an invented NDJSON schema. Display only `Your reviews`; no quota denominator, balance or reset is inferred. Disable CLI auto-update in the child environment. Current structured allowance support can be added after a real response/schema is available.
- **Gemini:** valid saved CLI access token only. Call loadCodeAssist to obtain its project, then retrieveUserQuota; no project-list enumeration, client-secret extraction or renewal. Consumer migration sentinel shows setup guidance; supported work tiers retain Pro/Flash/Flash Lite labels with no invented period. Pro enters history; the other model groups remain separate display/alert rows.
- **Hugging Face:** default `.cache/huggingface/token` saved by its CLI only. Fixed official GET `/api/spaces/zero-gpu/quota`, `base`/`current` GPU seconds and optional `resetsAt`. Billing permission is required; no inference spend/credit estimation or browser-wallet fallback. Official huggingface_hub `HfApi.get_zero_gpu_quota` and reference plugin informed the wire shape.

Shared SQLite reads are read-only and bounded; immutable mode is used without WAL. A WAL without an existing shared-memory file is unavailable, preventing sidecar creation. Changed/unsupported stores do not trigger credential migration. All new tools reuse opt-out, cadence, stale/429 handling and fixed-host/no-redirect transport. New fields are optional for saved-reading compatibility. Neutral letter tiles reuse Sketch frame 23; source was inspected live without edits/save. Website adds all nine plus the previously missing Kimi label, with a six-language limitations note. App sources shipped in 1.6.0/build 90; website deployment is owned by the user and remains unconfirmed.

Software/package evidence and remaining real-account checks: [APP-015](../tasks/APP-015-ai-usage-limits.md#browser-free-provider-expansion--2026-11-08).

## Scope and evidence

Preserve the existing contract: reuse an installed tool's saved sign-in; no Monny login, pasted keys, browser storage import, interactive Keychain access or Monny token renewal. Reading a key already saved by a tool is technically possible but is not automatically an approved expansion to arbitrary provider-key discovery. A CLI's own normal sign-in may open a browser; that differs from Monny extracting browser credentials.

Sources: current official vendor documentation plus MIT [CodexBar](https://github.com/steipete/CodexBar) at **7447bc77c2497323d9c41e40164ce705533493c8**. Its [provider inventory](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/providers.md) was screened for local sign-in, usage-only commands and local caches. Detailed docs and selected fetchers were read from that revision. CodexBar is an implementation reference, not provider endorsement or proof of live account compatibility. No code copied, dependency installed or new library proposed; Foundation, system SQLite and Monny's bounded command runner should cover the shortlisted source types. Snapshotting public source avoids relying on changing `main` links.

## Source references

The implementation decision above owns current behavior. These references retain the protocol evidence from the initial screening; they do not imply broader account or field coverage.

- **OpenCode Go:** [official plan documentation](https://opencode.ai/docs/console/go/), [CLI credential notes](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/opencodego.md), [usage fetcher](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/Sources/CodexBarCore/Providers/OpenCodeGo/OpenCodeGoUsageFetcher.swift), [vendor endpoint discussion](https://github.com/anomalyco/opencode/issues/52227). Model-dependent plan allowances do not establish per-model API meters.
- **Kilo:** [official CLI reference](https://kilo.ai/docs/code-with-ai/platforms/cli-reference), [credential resolver](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/Sources/CodexBarCore/Providers/Kilo/KiloBearerTokenResolver.swift), [usage fetcher](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/Sources/CodexBarCore/Providers/Kilo/KiloUsageFetcher.swift). Credential file: `~/.local/share/kilo/auth.json`. Monny omits the reference's payment-method request and organization discovery.
- **Kiro:** [source notes](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/kiro.md), [API reader](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/Sources/CodexBarCore/Providers/Kiro/KiroUsageLimitsAPI.swift). CLI store: `~/Library/Application Support/kiro-cli/data.sqlite3`; `auth_kv` key `kirocli:odic:token` supplies `access_token`, `state` key `api.codewhisperer.profile` supplies `arn`. POST GetUsageLimits to the profile's supported regional host. Chat fallbacks can create sessions or send slash commands to a model and are excluded.
- **Bailian:** [official usage commands](https://docs.agent.bailian.aliyun.com/en/bailian-cli/capabilities/usage-quota), [authentication](https://docs.agent.bailian.aliyun.com/en/bailian-cli/getting-started/installation), [official CLI source](https://github.com/modelstudioai/cli/tree/cadc301d078f0fd1f2c56f7bf94f32c55bbb055d), [earlier reference CLI reader](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/Sources/CodexBarCore/Providers/Alibaba/AlibabaTokenPlanCLIUsageFetcher.swift). Current official usage commands replace provisional custom console calls; Monny does not aggregate Team seats.
- **Windsurf:** [local-source notes](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/windsurf.md). SQLite `ItemTable` key `windsurf.settings.cachedPlanInfo` under `~/Library/Application Support/Windsurf/User/globalStorage/state.vscdb`; `quotaUsage` or newer `usage` counters. The cache updates while the app runs; database mtime cannot establish reading freshness.
- **CodeRabbit:** [official CLI reference](https://docs.coderabbit.ai/cli/reference#usage-command) documents 0.9.2 `usage --agent` with NDJSON caps/balances when permitted. That schema still needs a real sample; Monny currently reads the established text review count only. A shared cap would require explicit labeling, not a personal-quota assumption.

## Other sources and deferred extensions

- **Gemini CLI (implemented for eligible work accounts):** [Google's deprecation notice](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals) confirms the June 18 consumer OAuth shutdown and continued Standard/Enterprise support. The [reference](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/gemini.md) reads `~/.gemini/oauth_creds.json`, calls `retrieveUserQuota` and optionally `loadCodeAssist`. Monny reads the existing access token without renewal and uses distinct model-group labels. Personal Gemini app limits remain unsupported; live work-account agreement is open.
- **Hugging Face:** [reference](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/huggingface.md) reuses `hf auth login`'s saved token. Inference billing is spend, not a remaining allowance; ZeroGPU can expose a real quota. Billing permission and saved-key policy require review; prepaid wallet browser fallback is excluded. Monny implements ZeroGPU only; inference billing and wallet support remain deferred.
- **Muse Code:** [reference](https://github.com/steipete/CodexBar/blob/7447bc77c2497323d9c41e40164ce705533493c8/docs/muse.md) permits inline `providers.meta.access_token` in CLI metadata, but ordinary storage can require another app's Keychain grant. Quota can be omitted, and its `/muse-code/key` call mints an inference key rather than being a pure usage GET. Do not classify as a straightforward read-only candidate without resolving both concerns; no browser-team fallback.
- **Zed, Factory, Antigravity:** reviewed source families do not establish an equally simple qualifying path: Keychain prompts, separate/browser credentials or local-server discovery remain additional mechanisms. Factory's saved API key is not proof of reusable ordinary CLI OAuth. Exclusion is from this shortlist, not a claim of technical impossibility.
- API-key-only services (z.ai, MiniMax, OpenRouter, DeepSeek and others) remain outside this session's existing-sign-in shortlist unless a specific tool-owned source and appropriate quota endpoint are established. A public API alone does not establish either. Local model runners and token logs do not reveal a subscription's remaining quota.
