# Explicit process actions

Reviewed 2026-10-25 for [DES-004](../tasks/DES-004-power-search-quit-ai-tools.md). macOS 26+, ordinary-user access; no new dependency, helper, entitlement or privilege escalation.

Use AppKit's existing `NSRunningApplication.terminate()` for a normal app quit and `forceTerminate()` after explicit confirmation. Apple documents both as requests that can return before exit; a successful return must not remove a row or claim that an app exited. A normal quit can still show the target app's save dialog. If Launch Services has no running app for the selected PID, use Darwin `kill(pid, SIGTERM)` or `SIGKILL`. Never fall back to a signal after an app rejected its request, automatically escalate, or send to a process group. A force request also addresses individually validated members of the selected app group from the captured shared snapshot; new members are not discovered or pursued.

Native APIs satisfy the requirement, so a third-party process-control package adds no useful capability. No third-party implementation is copied. Sources: [Apple terminate](https://developer.apple.com/documentation/appkit/nsrunningapplication/terminate()), [forceTerminate](https://developer.apple.com/documentation/appkit/nsrunningapplication/forceterminate()), [thread-safe running-app objects](https://developer.apple.com/documentation/appkit/nsrunningapplication), [kill permissions and PID semantics](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/kill.2.html); installed SDK `sys/resource.h`, `sys/proc_info.h` and `libproc.h` confirm the launch-time/UID interfaces.

Keep `ri_proc_start_abstime` with sampled processes and cached app owners. Grouped rows use the owner's launch identity. PID reuse resets the reader's rate baseline and owner cache. Before each action, off the main actor, re-read launch identity, current UID and name. Reject missing/changed identities, other users, PID ≤1, Monny and loginwindow. Recheck standalone targets immediately before signalling. Darwin's PID-based signal API still has a small check-to-signal race; these checks reject stale UI targets but are not an atomic kernel identity-and-signal operation. Unknown identity exposes no menu. Helpers that have already exited need no signal; other member failures report a partial result.

One actor serializes explicit operations. The UI preserves the captured target through confirmation, disables overlapping actions, reports failures, and wakes the existing sampler loop after success or failure. Normal shared sampling reflects eventual exit; no exit polling timer or optimistic row deletion. Force Quit warns about unsaved changes and has a Cancel action. All copy is translated into the six product languages.

Verification and remaining app/keyboard/accessibility checks belong to DES-004. Integration tests may signal only a disposable `/bin/sleep` child started by that test; they never terminate an existing user application.
